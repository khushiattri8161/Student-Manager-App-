
# 📚 Student Manager App

A modern Student Management System built using Python Tkinter GUI.  
This application helps manage student records efficiently with features like adding students, viewing records, deleting entries, and checking results based on marks.

## ✨ Features
- ➕ Add Student Records
- 👀 View Student Details
- 🗑️ Delete Student Data
- 📊 Check Results & Grades
- 🎨 Modern Dark-Themed GUI
- 🧹 Clear Output Option

## 🛠️ Technologies Used
- Python
- Tkinter GUI
- File Handling / Dictionary
